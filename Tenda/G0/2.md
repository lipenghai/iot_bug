### description
A buffer overflow vulnerability was discovered in Tenda G0. Attackers can exploit this vulnerability by specifying the value of `staticRouteNet`. When `staticRouteNet` is passed from `formSetStaticRoute` into `addStaticRoute` and then formatted into the fixed-size stack buffer `s_` by `sprintf` without length validation, it may cause a buffer overflow.
